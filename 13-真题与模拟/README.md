## 使用方式

- 每次在软考达人或本地完成一组练习/模考，在此登记成绩与错题编号；
- 错题同步拆解进入 [14-错题本](../14-错题本/当前复习队列.md)，排入间隔复测；
- 可核验年份场次的真题统一记入 [真题索引](./真题索引.md)。
