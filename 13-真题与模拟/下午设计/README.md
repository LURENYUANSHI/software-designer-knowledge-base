# 下午 · 软件设计专项

软考软件设计师下午场固定五大题型（常选做 5 题，Java 语言）：
1. **数据流图（DFD）**：外部实体识别、数据存储识别、缺失数据流补全、父子图平衡检查；
2. **数据库设计**：E-R 图补全、联系基数判断、关系模式转换、主键与外键标注；
3. **面向对象与 UML 设计**：用例图/类图/序列图/状态图角色识别与关系填空；
4. **算法设计代码填空**：分治、动态规划、贪心、回溯（循环边界、递归终止、状态转移方程、复杂度分析）；
5. **设计模式 Java 代码填空**：接口/抽象类声明、多态委托、构造与回调、具体模式角色识别。

后续每次下午专项练习按 `YYYY-MM-DD-<题型或套次>.md` 存放于本目录。
