# 高频秒题技巧速查表

> 考前 10 分钟冲刺总览。每学完一个新模块或复盘完一套刷题，把可直接提速拿分的「秒杀口诀 / 公式 / 排除法」持续累加到这里。

## 01 · 计算机组成与体系结构（含多媒体 / 容错）
- **运算器 vs 控制器**：凡带「**指令、程序、译码、时序**」（IR、PC、ID、时序电路）全属**控制器**；ALU（核心为**加法器**）、累加器（AC）、PSW、DR、通用寄存器属**运算器**。
- **高频寄存器职责**：**PC** = 下一条/后继指令地址；**IR** = 当前正在执行的指令；**AR/MAR** = 主存单元地址。
- **取指第一步永远是 `PC → AR`**：执行任何指令前都先取指（`PC→AR` → `M→DR` → `DR→IR`）。
- **CPU 区分内存中指令与数据的依据**：**指令周期的不同阶段**（取指阶段取出来当指令，执行阶段取出来当数据）。
- **原码/反码/补码极值**：定点纯小数能表示 **`-1`**、8 位整数能表示 **`-128`** → **仅有补码**；负数原↔补速算：符号位不动，从右找第一个 `1`，它及右边照抄、左边数值位全取反；移码 = 补码符号位取反。
- **RISC vs CISC**：R = Reduced（**精简**指令 + **更多通用寄存器** + 定长 + 硬布线）；C = Complex（复杂指令 + 微程序）。
- **海明码唯一必背公式**：$2^k - 1 \ge n + k$（速记：`n=8→k=4`，`n=16→k=5`，`n=32→k=6`）。
- **总线分类**：**PCI = 并行内总线**；**SCSI = 并行外总线**；USB / SATA / PCIe = 串行总线。
- **屏蔽软件错误的冗余附加 3 件套**：冗余备份程序 + 错误检测与恢复程序 + 容错软件固化程序（**不含**「关键程序和数据的冗余存储及调用」，那是硬件容错！）。
- **多媒体分类**：**存储媒体** = 磁盘/光盘/磁带/半导体存储器（物理介质）；**感觉媒体** = 文字/图形/图像/声音；声卡/显示器属表现媒体。

## 02 · 操作系统
- **单处理机进程状态秒杀铁律**：同一时刻处于「**运行态**」的进程数 **≤ 1**（直接划掉有两个运行的选项！）；等待态不能直接跳运行态，必须先变就绪态。
- **进程三态触发词**：**运行 → 就绪 = 时间片到**（或被抢占）；运行 → 等待 = 请求 I/O；等待 → 就绪 = I/O 完成/资源释放。
- **绝对路径 vs 相对路径**：**绝对路径一定以 `\` 开头**（从根目录出发）；**相对路径绝不以 `\` 开头**（从当前工作目录出发）。

## 03 · 计算机网络与信息安全
- **多址复用秒分**：分频率 = FDM；分时间片 = TDM；**同时间 + 同频带** = **码分复用（CDMA）**。
- **IPv4 类别首字节速记**：A 类 `1~126`（`127` 本地回环）；B 类 `128~191`；**C 类 `192~223`**；D 类 `224~239`（组播）；E 类 `240~255`。
- **ARP 报文**：**ARP Request = 广播**（全网喊话问 MAC）；**ARP Response = 单播**（点对点回复）。
- **加密与数字签名三大阵营**：
  - **对称加密**：DES、3DES、AES、IDEA、RC4（同密钥加解密，不能数字签名）
  - **非对称加密 / 数字签名**：**RSA**、ECC、DSA（私钥签名、公钥验签）
  - **消息摘要 / 哈希**：MD5、SHA（不可逆摘要，不能单独签名）
- **安全协议分层**：链路层 PPTP/L2TP；**网络层（加密 IP 报文）= IPSec**；传输层 SSL/TLS；应用层 HTTPS/SSH/PGP。
- **HTML 常用标签**：`<TITLE>` 标题、`<HR>` 水平分隔线、`<I>` 斜体、`<TR>` 表格行。

## 04 · 数据库系统
- **候选码 L-R-N 秒杀法**：**L 类（仅在左）+ N 类（均未出现）** 必在每个候选码中；**R 类（仅在右）** 必不在候选码中；单属性决定全表时千万别多塞冗余属性破坏极小性。
- **主属性个数**：所有候选码的**并集**大小（不是交集！）。
- **范式与异常**：有部分依赖 → 仅 1NF；消部分依赖、仍有非主属性传递依赖 → 仅 **2NF（仍存在冗余与插入/删除异常）**；无部分依赖且无传递依赖 → **3NF**。
- **故障恢复 WAL 原则**：事务增删改内容**先写日志文件**；系统正常运行时定时把缓冲区脏页写入**数据文件**。

## 05 · 数据结构（兼 08 项目管理）
- **四种存储结构**：物理相邻 = 顺序；指针相连 = 链表；另建索引表 = 索引；**地址与关键字有函数映射** = **散列（Hash）**。
- **AOE 最少工期**：反直觉！完成整个项目的「最少时间」= 起点到终点的**最长路径**（关键路径）。
- **活动松弛时间（10 秒公式）**：
  $$\text{松弛时间}(u \to v) = \text{关键路径总长} - (\text{起点到 } u \text{ 最长} + w(u,v) + v \text{ 到终点最长})$$

## 06 · 算法设计与分析
- **四大策略关键词**：局部最优不回退 = **贪心**；重叠子问题填表 = **动态规划**；独立子问题递归合并 = **分治**；DFS 剪枝回退 = **回溯**。
- **主定理高频坑**：$T(n)=2T(n/2)+n \Rightarrow \Theta(n\log n)$；但 **$T(n)=2T(n/2)+n\log n \Rightarrow \Theta(n\log^2 n)$**（每层代价都是 $n\log n$，共 $\log n$ 层，别漏掉平方！）。
- **装配线调度 DP**：单重循环 $\Theta(n)$；手算最短路径时按列逐站取 `min`，**千万别漏斜边切换代价**；注意与 AOE 区分（装配线只走一条路求**最短**，AOE 并行全做求**最长**）。
- **一维区间点覆盖**：给「覆盖半径 $m$」时单次跨度是 **$2m$**，每次从最左未覆盖点 $x$ 直接框到 $x + 2m$。

## 08 · 软件工程
- **面向对象测试四层**：**算法层 = 单元测试**（测单方法）；类层 = 模块测试；模板层 = 集成测试；系统层 = 系统测试。
- **CMM 5 级方向与特征**：**1 级最低 → 5 级最高**（1 初始 → 2 可重复 → **3 已定义：组织级标准化/文档化** → 4 已管理 → 5 优化级）；高级满足低级，故标准化/文档化覆盖 **3、4、5 级**。
- **逆向工程**：已有代码反推设计，发生在交付后的**软件维护阶段**。
- **XP 极限编程结对编程**：提升代码质量、非正式审查、共同代码所有权；**不能加快单纯编码速度**。
- **结构化分析三大图形**：**系统逻辑模型 / 数据处理流程 = 数据流图（DFD）**；数据模型 = E-R 图；行为模型 = 状态转换图。

## 09 · 面向对象与 UML（看图秒题）
- **对象通信**：对象之间通过发送**消息**请求服务。
- **六大类图关系 3 秒判定**：
  - 虚线只有 2 个：普通箭头 = **依赖**，空心三角 = **实现（`implements`）**；
  - 空心三角只有 2 个：实线 = **泛化/继承（`extends`）**，虚线 = **实现**；
  - 菱形永远贴在**整体**一端：**空心聚合可拆散，实心组合同生死**；强弱：**组合 > 聚合 > 关联 > 依赖**。
- **用例图箭头方向**：`<<include>>`（必做）由**主用例 → 被包含用例**；`<<extend>>`（可选）由**扩展用例 → 主用例**（反着指回主用例！）。
- **九大 UML 图一眼辨认**：3D 立体块 = 部署图；插头/棒棒糖 = 构件图；小人+椭圆 = 用例图；下划线实例名 = 对象图；纵向虚线生命线 = 序列图；无时间轴但有 `1.1:` 编号 = 通信图；圆角状态+黑圆起点 = 状态图；菱形+粗黑并行条+泳道 = 活动图。

## 10 · 设计模式（GoF 23 种）
- **类模式 vs 对象模式 2 秒口诀**：
  > **「工适解模」是类模式，其余 19 种全为对象模式！**
  > - 创建型类模式（1）：**工**厂方法（Factory Method）
  > - 结构型类模式（1）：类**适**配器（Adapter）
  > - 行为型类模式（2）：**解**释器（Interpreter）、**模**板方法（Template Method）
- **三大阵营快速归类**：
  - **创建型（5）**：单例、工厂方法、抽象工厂、建造者/构建器、原型
  - **结构型（7）**：适配器、桥接、**组合**、装饰器、外观、享元、代理
  - **行为型（11）**：策略、观察者、模板方法、状态、**责任链**、命令、迭代器、**中介者**、备忘录、访问者、解释器
- **高频类图/题干秒杀词**：`clone()` = 原型；自关联 `next` + 动态指定处理者集合 = 责任链（行为型对象）；中间双向协调 = 中介者（行为型对象）；左右两树架桥 = 桥接；`0..*` 树形容器 = 组合；`1:1` 包装增强 = 装饰器。

## 11 · 知识产权与标准化
- **安全/卫生标准一刀切**：凡涉及**保障人体健康、人身财产安全、工业产品安全与卫生要求**的国家/行业/省级地方标准，在其适用范围内一律是**强制性标准**。
