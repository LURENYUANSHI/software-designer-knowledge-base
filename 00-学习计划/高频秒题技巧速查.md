# 高频秒题技巧速查表

> 考前 10 分钟冲刺总览。每学完一个新模块或攻克一道高频错题，把可直接提速拿分的「秒杀口诀 / 公式 / 排除法」持续累加到这里。

---

## 01 · 计算机组成与体系结构
- **运算器 vs 控制器**：凡带「**指令、程序、时序**」（IR、PC、ID、时序电路）全属**控制器**；ALU、累加器（AC）、PSW、DR、通用寄存器属**运算器**。
- **原码/反码/补码极值**：定点纯小数能表示 **`-1`**、8 位整数能表示 **`-128`** → **仅有补码**（因为补码 0 唯一，腾出 `-0` 的编码表示最小负数）。
- **负数原码↔补码速算**：符号位不动，从右往左找**第一个 `1`**，它及右边照抄，它左边数值位全取反。
- **移码速算**：补码**符号位取反**即移码。

## 04 · 数据库系统
- **候选码 L-R-N 秒杀法**：
  1. **L 类（仅在左）+ N 类（均未出现）** → **必在所有候选码中**（直接划掉不含它们的错误选项）。
  2. **R 类（仅在右）** → **绝对不在任何候选码中**。
  3. 求 $(L \cup N)^+$，若已等于 $U$ 则唯一候选码到手；否则逐个补 **LR 类**属性测试极小超码。
- **主属性个数**：所有候选码的**并集**大小（不是交集！）；非主属性 = 总属性数 − 主属性数。

## 05 · 数据结构（兼 08 项目管理）
- **AOE 最少工期**：反直觉！完成整个项目的「最少时间」= 起点到终点的**最长路径**（关键路径）。
- **活动松弛时间（10 秒公式）**：
  $$\text{松弛时间}(u \to v) = \text{关键路径总长} - (\text{起点到 } u \text{ 最长} + w(u,v) + v \text{ 到终点最长})$$
- **关键活动特征**：松弛时间必为 **0**；压缩工期必须压缩所有关键路径共有的关键活动。

## 06 · 算法设计与分析
- **四大策略关键词**：
  - 局部最优 + 不回退 → **贪心**
  - 重叠子问题 + 状态转移填表 → **动态规划**
  - 拆分独立子问题 + 递归合并 → **分治**
  - DFS 试探 + 剪枝 + 撤销回退 / 求全解 → **回溯**
- **一维区间点覆盖**：给「覆盖半径 $m$」时单次跨度是 **$2m$**，每次从最左未覆盖点 $x$ 直接框到 $x + 2m$。

## 10 · 设计模式（GoF 23 种）
- **类模式 vs 对象模式 2 秒口诀**：
  > **「工适解模」是类模式，其余 19 种全为对象模式！**
  > - 创建型类模式（1）：**工**厂方法（Factory Method）
  > - 结构型类模式（1）：类**适**配器（Adapter）
  > - 行为型类模式（2）：**解**释器（Interpreter）、**模**板方法（Template Method）
- **高频类图/题干秒杀词**：
  - `clone()` / `Cloneable` / 复制自身 → **原型（创建型·对象）**
  - 自关联 `next`/`successor` / 沿链传递请求 / 动态指定处理者集合 → **责任链（行为型·对象）**
  - 用一个对象封装一系列对象交互 / 取消显式相互引用 → **中介者（行为型·对象）**
  - 封装多种可互换算法 / 消除多重 `if/else` → **策略（行为型·对象）**
  - 保存内部状态快照 / 撤销恢复 → **备忘录（行为型·对象）**
  - 给复杂子系统提供统一简化对外入口 → **外观（结构型·对象）**
