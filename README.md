| 科目 | 题型 | 时长 | 满分 | 合格线 |

## 三、学习方法与互动流程

本项目内置 [.agents/skills/study/SKILL.md](./.agents/skills/study/SKILL.md)，将本目录设为工作区后，直接对 AI 说「开始学习」「继续学习」「复习错题」「查看进度」或丢一个软考达人模考链接即可自动进入闭环：

1. **到期复测优先**：先读 `14-错题本/当前复习队列.md`，对到期错题做脱离原解析的换题复测（连续 2 次延迟换题答对才归档）。
2. **最小考点循环**：讲点（定义/要点/易错点/真题考法）→ 问答 → 5 题自适应验收 → 真题校准 → 个人记忆点。
3. **外部刷题累加**：在软考达人等平台刷完「每日一练」或模考后，将错题导入 `14-错题本/活动错题/错NNN.md`，自动更新复习队列、错题索引、模块进度与考点笔记。
4. **Study Transaction**：每次学完或复测完，同步更新笔记、模块进度、检查点、日期日志和错题队列，并 `git commit && git push` 留痕。

## 四、外部题源分级与掌握状态

| 状态 | 含义 |
| --- | --- |
| `⬜` | 未开始 |
| `🟦` | 学习中 / 教学完成，待真题校准或待延迟复测 |
| `🟨` | 初步掌握（基础验收 + 外部真题校准完成），待延迟复测 |
| `✅` | 延迟复测通过，稳定掌握 |

| 题源等级 | 含义 | 校准用途 |
| --- | --- | --- |
| A｜可核验真题 | 官方样题、年份场次可核验的历年真题/考生回忆版 | 可用于校准 |
| B｜权威题库真题 | 软考达人等权威题库收录的真题（年份待核验） | 可用于校准 |
| C｜真题型训练 | 同考法训练题或真题改编题 | 仅用于训练 |
| D｜自适应原创 | 针对个人错因生成的变式补强题 | 仅用于补强 |
