# 错题本

> 做错的题一律进这里，按 `D+1 → D+3 → D+7 → D+14` 间隔复测；脱离原解析**连续两次延迟换题答对**后才归档。

## 文件说明

- [当前复习队列.md](./当前复习队列.md) — 每次学习的轻量调度入口（只保留未归档活动错题）
- [错题索引.md](./错题索引.md) — 全部错题的全局编号、状态与错因速览
- [活动错题/](./活动错题) — 一题一文件（`错001.md`、`错002.md`…），保存完整错因、正确判据与复测历史
- [已归档/](./已归档) — 连续 2 次延迟换题答对后的归档区

## 复习规则

1. **新错即入队**：发现知识性错误，立刻分配 `#错NNN`、建独立文件、安排 `D+1`。
2. **同日不计延迟**：当天补讲或当场做对变式题记入「当场补强」，**不计入延迟复测通过次数**。
3. **复测必换题**：复测时严禁直接重看原题解析后背答案，必须由 AI 另出同错因变式题检验。
4. **2/2 归档与防反弹**：连续两次延迟换题答对后标记 `✅` 归档；若后续隔日再次暴露同类错误，重新激活并重排 `D+1`。
