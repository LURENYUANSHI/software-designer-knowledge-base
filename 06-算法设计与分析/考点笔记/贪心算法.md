# 贪心算法与一维区间覆盖

> 模块：06 算法设计与分析 ｜ 状态：🟦（错题建档，待正式 5 题自适应验收与真题校准） ｜ 创建：2026-11-26

## 定义
**贪心策略（Greedy）**：在求解最优化问题时，每一步都做出在**当前状态下看来最好（局部最优）**的选择，一旦做出选择便**不再回退**，希望由此导出全局最优解。

## 要点

### 1. 四大算法设计策略对比
| 策略 | 核心特征 | 典型考题关键词 | 最优性特征 |
| --- | --- | --- | --- |
| **分治** | 拆成互不相交的子问题，递归求解后合并 | 二分查找、归并排序、快排、主定理 | 求解精确问题 |
| **动态规划** | 重叠子问题 + 最优子结构，自底向上填表/记忆化 | 0-1 背包、LCS、矩阵连乘、最短路 | 总能得到一个最优解 |
| **贪心** | 局部最优选择，不回退、不维护全局状态表 | 活动选择、哈夫曼编码、MST、部分背包、消防栓覆盖 | **仅当具备贪心选择性质时保证最优；一般而言对有些问题可能得不到最优解** |
| **回溯** | 深度优先搜索解空间树 + 剪枝，失败则回退 | N 皇后、0-1 背包求全解、迷宫、图着色 | 可求出所有可行解/最优解 |

### 2. 经典案例：笔直公路消防栓覆盖（关联 `#错003`、`#错004`、`#错005`）
- **规则**：从最左端未覆盖房子起，在其右侧 $m$ 米（半径）处装一个消防栓，删去被覆盖的所有房子，重复。
- **单次覆盖跨度**：半径 $m = 20$ 米 → 装在 $x + 20$ 处，覆盖区间为 $[x,\; x + 40]$，跨度 **$2m = 40$ 米**！
- **手算模拟**：房子坐标 `(10, 20, 30, 35, 60, 80, 160, 210, 260, 300)`：
  1. `10` → 装在 `30`，覆盖 `[10, 50]` → `{10, 20, 30, 35}`
  2. `60` → 装在 `80`，覆盖 `[60, 100]` → `{60, 80}`
  3. `160` → 装在 `180`，覆盖 `[160, 200]` → `{160}`
  4. `210` → 装在 `230`，覆盖 `[210, 250]` → `{210}`
  5. `260` → 装在 `280`，覆盖 `[260, 300]` → `{260, 300}`
  - 时间复杂度：$\Theta(n)$（已排序时遍历一次），最少需要 **5 个**消防栓。

## 易错点
1. **半径 vs 直径算错**：消防栓覆盖半径 20 米，意味着左侧 20 米 + 右侧 20 米 = 覆盖宽度 **40 米**，所以 `260` 和 `300` 相距 40 米只需 1 个消防栓（装在 280）。
2. **真题/题库争议提醒（`#错005`）**：
   - 从严格数学证明看，一维数轴定长区间覆盖点集**满足贪心选择性质**，该算法一定能得最优解；
   - 但软考达人题库将第 4 空按「贪心算法通用局限性」判选 **C（有些实例，可能得不到最优解）**，刷题时注意区分「通用贪心结论」与「具体问题是否满足贪心选择性质」。

## 真题考法
- 上午常出 4 联空题组：策略名称（贪心）+ 时间复杂度 + 给定样例手算结果 + 策略性质判断。

## 秒题技巧
1. **四大策略关键词 3 秒区分**：
   - 「每步选当前最优 / 不回退 / 不查表」→ **贪心**
   - 「重叠子问题 / 状态转移方程 / 填表」→ **动态规划**
   - 「划分为独立子问题 / 递归求解合并」→ **分治**
   - 「深度优先搜索 / 剪枝 / 撤销回退 / 求全部解」→ **回溯**
2. **区间覆盖半径必乘 2**：题干给「覆盖半径 $m$」时，单次最大覆盖跨度是 **$2m$**（从当前最左未覆盖点 $x$ 直接框到 $x + 2m$），扫一遍数组即可数出最少数量，绝不漏算左侧覆盖。
